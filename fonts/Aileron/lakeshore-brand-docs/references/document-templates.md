# Document Templates — Structure Reference

This file defines the standard structures for each document type. When a user asks for a document, use the matching template and fill in the content based on their input.

---

## 1. Project Proposal (Angebotsvorlage)

This is Lakeshore Media's primary client-facing document. It's a 16:9 landscape presentation-style PDF.

### Page Structure

**Cover Page**
- Top line: "PRESENTED TO: [Client Name]" (left) | "CREATED BY: Raeto Königsbauer" (right)
- Horizontal rule
- Large title: "PROJECT PROPOSAL" in display font
- Orange accent arrow icon (↗) right of center
- Bottom: Date (left) | Website URL (right)
- Footer: "LAKESHORE MEDIA" (left) | Logo icon (center) | -- (right)

**Contents Page**
- "CONTENTS" header with horizontal rule
- 8 numbered sections in display font:
  1. OVERVIEW — Concept, Format
  2. PROJECT MISSION — Video/Photo/Content Goals
  3. DELIVERABLES — Featured Products, Usage & Placement
  4. MOOD BOARD — Early Ideas, References, Messaging
  5. TONE/FEEL — Art Direction, Editing Style
  6. TIMELINE — Pre-Production, Shoot Days, Deadlines
  7. INVESTMENT — Quote, Link to Invoice
  8. NEXT STEPS — Contact Details

**1. Overview Page**
- Section number + "OVERVIEW" header + subtitle
- AI-generated or placeholder hero image area
- Two-column layout:
  - Left: [Approach 1 - General Package] with deliverable description
  - Right: [Approach 2 - Video Concept] with concept description
- Important: Frame the content around the CLIENT's needs, not Lakeshore's capabilities

**2. Project Mission Page**
- 4-column grid with image placeholders
- Each column: numbered goal with description
- Goals should be specific to the client's project (not generic)

**3. Deliverables Page(s)** (can be 1-2 pages)
- 4-column layout showing each deliverable:
  - Video 1 (with device mockup)
  - Video 2 / Social Media Cut
  - Photography Package
  - BTS Raws (optional add-on)
- Each with: title, description, specs (duration, format, resolution)
- Pricing version: adds "STARTING FROM $X" badges
- Bottom: Licensing terms

**4. Mood Board Page(s)** (2-3 pages)
- Image grid with reference photos/stills
- Short script phrases
- Visual ideas + sound design notes

**5. Tone/Feel Page**
- Art direction description
- Reference styles, editing approach
- Color mood, pacing notes

**6. Timeline Page**
- Phase breakdown with dates:
  - Pre-Production
  - Shoot Day(s)
  - Post-Production
  - Delivery/Review

**7. Investment Page**
- Package pricing table
- Payment terms
- Link to invoice/booking

**8. Next Steps Page**
- Call to action
- Contact details (Raeto Königsbauer, phone, email)
- Meeting booking link if applicable

### Design Notes for Proposals
- Background: Steel Blue (#2E3D51) as primary, with dark charcoal sections
- Light pages: Off-White (#ECEAE4) for mood board and overview
- Organic gray shapes as corner accents
- Orange arrows (↗) as accent elements
- Display font for all numbered section headers
- Generous whitespace — don't overcrowd slides

## 2. Lead Magnet / Freebie PDF

Portrait A4 format, designed for download and lead generation.

### Typical Structure
- **Cover**: Bold title in display font, subtitle, Lakeshore branding
- **Intro Page**: Brief context, what the reader will learn
- **Content Pages**: 5-15 pages depending on depth
  - Use numbered frameworks, checklists, or step-by-step processes
  - Each page should have a clear takeaway
  - Mix of text and visual elements (icons, illustrations, data callouts)
- **Summary/CTA Page**: Key takeaways, call to action, contact info

### Design Notes for Freebies
- Can use either dark or light theme (dark feels more premium)
- Include Lakeshore branding but make it about VALUE, not self-promotion
- Each page should stand alone as a screenshot (for social sharing)
- Use large numbers, bold stats, and visual hierarchy aggressively

## 3. E-Mail Mailing / Anschreiben

A4 portrait, single-page or 2-page format.

### Structure
- Lakeshore logo/wordmark at top
- Date and recipient info
- Greeting (informal "Du" style)
- Body: 2-4 short paragraphs, clear and direct
- Call to action
- Signature block with contact details
- Footer with branding

### Design Notes for Mailings
- Cleaner, simpler design — less visual noise
- Light background works well for readability
- Aileron for all text (no display font needed except maybe the header)

## 4. Pitch Deck (16:9 Präsentation)

For Canva output. More visual, less template-driven.

### Typical Flow
1. Cover slide (brand name, client name, date)
2. Problem/Challenge slide
3. Solution/Approach slide
4. Process overview
5. Portfolio/Case studies (2-3 slides)
6. Team/About
7. Pricing/Packages
8. Next Steps/CTA

### Design Notes for Pitch Decks
- This is where the full visual identity shines
- Use organic shapes, photography, illustrations
- RL Aqva for all hero text (available in Canva brand kit)
- Leverage Canva MCP to create editable designs the user can refine
- Dark theme as default; consider light accent slides for variety
