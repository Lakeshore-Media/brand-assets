### Freebie — Usage Notes for the Skill

- **Keep the visual skeleton**: Don't delete the A2..A8 / B1..B8 hidden slots on page 2 — they hold the stacked layout together. Only replace the visible A1..A8 titles.
- **Repurposing**: For a *new* freebie on a different topic, override cover (p.1), TOC (p.2 · A1..A8), intro (p.3), all 5 Baustein pages (9–12), Quick Wins (p.14), Checkliste (p.17), and CTA (p.18). Leave case studies (p.5), about (p.4), and home-setup (p.16) unless explicitly asked.
- **Content volume check**: Each bullet block is sized for 3–5 short lines. If generated content is longer, reduce or risk overflow.
- **Consistent footer**: Every page has a `lakeshore media` / `10x roas framework` footer pair — if the doc is re-titled, update these on every page.
